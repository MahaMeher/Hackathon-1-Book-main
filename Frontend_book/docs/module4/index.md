# Module 4: Vision-Language-Action (VLA)

Welcome to Module 4, where we explore how language models, vision, and robotics converge to enable autonomous humanoid behavior. This module builds on your existing knowledge of ROS 2, simulation, and basic AI concepts to introduce you to Vision-Language-Action systems.

## About This Module

Vision-Language-Action (VLA) systems represent the cutting edge of robotics, where language models, computer vision, and robotic control work together to create truly autonomous systems. In this module, you'll learn how to create robots that can understand natural language commands, perceive their environment, and execute complex tasks autonomously.

## Chapters

1. [Voice-to-Action Interfaces](./chapter1-voice-to-action.md) - Learn about voice command pipelines, speech-to-text using Whisper, and mapping voice input to robot intents
2. [Cognitive Planning with LLMs](./chapter2-cognitive-planning.md) - Explore translating natural language into action plans and task decomposition into ROS 2 actions
3. [Capstone – The Autonomous Humanoid](./chapter3-capstone-autonomous-humanoid.md) - Understand end-to-end system architecture with navigation, perception, and manipulation flow

## Learning Objectives

By the end of this module, you will:
- Understand VLA pipelines and their components
- Be able to explain language-to-action planning
- Understand the full autonomous humanoid system
- Know how to implement integrated VLA systems using high-level design approaches
