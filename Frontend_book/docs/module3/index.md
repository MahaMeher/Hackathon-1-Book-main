# Module 3: The AI-Robot Brain (NVIDIA Isaac™)

Welcome to Module 3, where we explore advanced perception, navigation, and training for humanoid robots using NVIDIA Isaac. This module builds on your existing knowledge of ROS 2 and simulation concepts to introduce you to NVIDIA's powerful robotics platform.

## About This Module

NVIDIA Isaac is a comprehensive robotics platform that combines simulation, perception, and navigation capabilities to accelerate the development of AI-powered robots. In this module, you'll learn how to leverage Isaac's capabilities for creating intelligent humanoid robots.

## Chapters

1. [NVIDIA Isaac Sim Overview](./chapter1-isaac-sim-overview.md) - Learn about photorealistic simulation, synthetic data generation, and perception model training
2. [Isaac ROS for Perception & Localization](./chapter2-isaac-ros-perception.md) - Explore hardware-accelerated vision pipelines and Visual SLAM
3. [Navigation & Motion Planning](./chapter3-navigation-motion-planning.md) - Understand Nav2 architecture and bipedal humanoid navigation

## Learning Objectives

By the end of this module, you will:
- Understand Isaac's role in AI robotics
- Be able to explain perception and VSLAM pipelines
- Understand humanoid navigation concepts
- Know how to implement advanced robotics applications using NVIDIA Isaac
