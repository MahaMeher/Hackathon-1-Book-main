# Data Model: Retrieval Validation & Pipeline Testing

## Entity: SearchQuery
**Description**: Represents a user's text query that is converted to embeddings for semantic search

**Fields**:
- `query_text`: string (required) - The original text query
- `embedding`: array<float> (required) - The embedding vector generated by Cohere
- `model_used`: string (required) - Name of embedding model (e.g., "embed-english-v3.0")
- `input_type`: string (required) - Cohere input type ("search_query")
- `timestamp`: datetime (required) - When query was processed

**Validation**:
- Query text must not be empty (after stripping whitespace)
- Embedding must have correct dimensionality (1024 for embed-english-v3.0)
- Model used must match configured model

## Entity: RetrievedChunk
**Description**: Represents a text chunk retrieved from vector search, containing content and metadata

**Fields**:
- `chunk_id`: string (required) - Unique identifier from Qdrant
- `content`: string (required) - The text content of the chunk
- `similarity_score`: float (required) - Cosine similarity score (typically 0.0 to 1.0)
- `source_url`: string (required) - URL of original source page
- `section`: string (required) - Book section/chapter name
- `chunk_index`: integer (required) - Index within source page
- `model_used`: string (required) - Embedding model used during ingestion
- `generated_at`: datetime (required) - When chunk was originally created
- `vector_id`: string (optional) - Original vector ID from Qdrant payload

**Validation**:
- Similarity score must be between -1.0 and 1.0 (valid cosine similarity range)
- Source URL must be valid URL format
- Chunk index must be non-negative
- Content must not be empty

## Entity: RetrievalResult
**Description**: Represents the complete result set for a query, including retrieved chunks and metadata

**Fields**:
- `result_id`: string (required) - Unique identifier for this result set
- `query_text`: string (required) - Original query text
- `query_embedding_model`: string (required) - Model used for query embedding
- `retrieved_chunks`: list[RetrievedChunk] (required) - List of top-k retrieved chunks
- `total_results`: integer (required) - Number of chunks retrieved (should equal k)
- `execution_time_ms`: integer (required) - Total query execution time
- `embedding_time_ms`: integer (required) - Time to generate query embedding
- `search_time_ms`: integer (required) - Time for Qdrant similarity search
- `timestamp`: datetime (required) - When query was executed
- `top_k`: integer (required) - Number of results requested

**Validation**:
- Total results must equal length of retrieved_chunks list
- Total results must be <= top_k
- Execution time must equal embedding_time + search_time (approximately)
- Execution time must be positive
- Retrieved chunks list must not be empty for successful queries

## Entity: ValidationResult
**Description**: Represents validation outcome for a retrieval test

**Fields**:
- `validation_id`: string (required) - Unique identifier for validation
- `result_id`: string (required) - Reference to RetrievalResult being validated
- `metadata_completeness`: boolean (required) - True if all chunks have complete metadata
- `metadata_issues`: list[string] (optional) - List of metadata validation issues found
- `url_valid`: boolean (required) - True if source URLs are valid format
- `url_invalid`: list[string] (optional) - List of invalid URLs found
- `relevance_score`: float (optional) - Computed relevance score (0.0 to 1.0)
- `relevance_assessment`: string (required) - Overall assessment: "high", "medium", "low", "none"
- `passes_criteria`: boolean (required) - True if result passes all validation criteria
- `validation_timestamp`: datetime (required) - When validation was performed

**Validation**:
- Relevance score must be between 0.0 and 1.0 when provided
- Relevance assessment must be one of: "high", "medium", "low", "none"
- If passes_criteria is True, metadata_completeness and url_valid should be True

## Entity: QuerySession
**Description**: Represents a complete validation session with multiple queries

**Fields**:
- `session_id`: string (required) - Unique identifier for session
- `start_time`: datetime (required) - When session started
- `end_time`: datetime (optional) - When session completed (null if running)
- `status`: string (required) - Session status: "running", "completed", "failed"
- `total_queries`: integer (required) - Number of queries executed
- `successful_queries`: integer (required) - Number of successful queries
- `failed_queries`: integer (required) - Number of failed queries
- `avg_execution_time_ms`: float (optional) - Average query execution time
- `avg_relevance_score`: float (optional) - Average relevance score across queries
- `determinism_verified`: boolean (required) - True if repeated queries returned same results
- `qdrant_collection`: string (required) - Name of Qdrant collection used
- `collection_vector_count`: integer (required) - Total vectors in collection

**Validation**:
- Total queries must equal successful + failed queries
- Status must be one of: "running", "completed", "failed"
- Count values must be non-negative
- Average values must be positive when provided
- End time must be after start time when provided
