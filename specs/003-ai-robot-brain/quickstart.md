# Module 3 - The AI-Robot Brain (NVIDIA Isaac™) - Quickstart Guide

## Overview
This module covers advanced perception, navigation, and training for humanoid robots using NVIDIA Isaac. It's designed for students familiar with ROS 2 and simulation concepts.

## Prerequisites
- Understanding of ROS 2 fundamentals
- Basic simulation concepts
- Familiarity with robotic systems

## Module Structure
1. **Chapter 1**: NVIDIA Isaac Sim Overview
   - Photorealistic simulation
   - Synthetic data generation
   - Perception model training

2. **Chapter 2**: Isaac ROS for Perception & Localization
   - Hardware-accelerated vision pipelines
   - Visual SLAM (VSLAM)
   - Sensor data integration with ROS 2

3. **Chapter 3**: Navigation & Motion Planning
   - Nav2 architecture
   - Path planning concepts
   - Bipedal humanoid navigation overview

## Key Learning Outcomes
- Understanding Isaac's role in AI robotics
- Ability to explain perception and VSLAM pipelines
- Understanding of humanoid navigation concepts

## Getting Started
1. Review the prerequisites
2. Start with Chapter 1 to understand Isaac Sim
3. Progress through each chapter sequentially
4. Complete hands-on exercises as you progress
